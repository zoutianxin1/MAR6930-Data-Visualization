# MAR6930 Data Visualization

Course materials for MAR 6930 Special Topic (Data Visualization), Warrington College of Business, University of Florida.

Course document (Fall 2026 MOD 2): https://docs.google.com/document/d/1SBMHcK5rY3BfYncUkNYf708lUGFVzv2eh3V_0nzIvpI/edit

## Downloading a file

1. Open the file's page in this repository (the course document links to each one).
2. Click the "Download raw file" button (the download arrow at the top right of the file view).

Save each notebook and its CSV data file in the same folder on your computer. The notebooks read the data from their own folder.
